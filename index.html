Logic Explanation

The application stores the loot in an array named lootItems. Each time a valid item is added, JavaScript creates an object with a name property and a value property, then adds that object to the array with push().

A traditional indexed for loop goes through the array to calculate the total value. A second loop displays every loot object in the Loot List. The if statements check that the loot name and value are valid before an item is added. Before splitting, another set of conditions checks that the party size is a whole number of at least 1 and that the array contains loot.

Event listeners wait for the Add Loot and Split Loot buttons. When a button is clicked, its function runs and updates the page. The array stays in memory while the page is open, so the user does not need to reload or save the list.
